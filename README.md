# Tanishq Jaiswal

I'm a Full Stack Developer with a focus on Generative AI and Agentic AI applications. I primarily work with the MERN stack and have hands-on experience building AI-powered applications using LangChain, LangGraph, RAG, and MCP.

I enjoy building applications that combine frontend development, backend systems, and AI capabilities.

My work includes building:

- Full-stack applications using React.js, Next.js, Node.js, Express.js, and MongoDB.
- AI agents with LangChain, LangGraph, and MCP Server/Client integration.
- Hybrid RAG pipelines using dense and BM25 sparse retrieval, reranking, and retrieval evaluation.
- Multi-step tool-calling workflows that connect LLMs with external services.
- Retrieval evaluation using Recall@K, MRR, and nDCG metrics.
